BFV-Based Searchable Cloud Encryption System

MSc Applied Research Project (Level 9)
Python TenSEAL FastAPI AWS (EC2) Terraform Nginx

Engineered a three-layer hybrid cryptographic architecture combining BFV (Homomorphic Encryption for data in-use), AES-128 (Fernet for data at-rest), and TLS/HTTPS via Nginx (data in-transit) to enable zero-trust Disjunctive Normal Form (DNF) boolean queries over encrypted cloud storage[cite: 1, 2].

  • Provisioned memory-optimized AWS EC2 infrastructure using Terraform and built an asynchronous FastAPI backend supporting parallel homomorphic matrix-vector dot products[cite: 1, 2].
  • Evaluated latency, ciphertext size, and noise budget consumption across scaling datasets with automated unit testing achieving 100% test coverage via Pytest[cite: 2].
